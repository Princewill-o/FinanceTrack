# FinanceTrack

Personal Finance Tracker with Notion design aesthetics, UK tax calculations, interactive charts, event calendar forecasting, dynamic formula-driven Excel exports, and Firebase Cloud Authentication & Database storage.

## Features
- **Notion Design Aesthetics**: Clean monochrome look, callouts, dark/light theme switch.
- **UK Tax & NI Engine**: Calculates basic/higher rate tax and National Insurance automatically.
- **Charts & Diagrams**: Visual Cash Flow diagram, expense breakdown doughnut chart, 12-month projection bar chart.
- **Interactive Excel (.xlsx) Export**: Live Excel formulas (`=SUM()`, `=NetPay - Outgoings`).
- **Firebase Auth & Database**: User signup, signin, and live cloud state persistence.

## Run Locally
Simply open `index.html` in any modern web browser.
